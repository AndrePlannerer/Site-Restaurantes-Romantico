# Restaurantes Românticos — Liberdade, São Paulo

Site estático de uma página com a pesquisa de restaurantes para um date na Liberdade, numa quinta-feira à noite.

## Etapas

1. **Date na Liberdade, quinta à noite** — izakayas e restaurantes abertos na quinta, com horários.
2. **Aniversário de namoro** — opções mais caprichadas para a comemoração.
3. **Estimativa de preço** — quanto o casal deve gastar em cada lugar, com fontes.

## Como abrir

Abra o `index.html` no navegador. Não há build nem dependências além das fontes do Google Fonts.

Para publicar no GitHub Pages: *Settings → Pages → Deploy from a branch → `main` / root*.

## Observações

- Horários e telefones vêm do Google Maps (consultados em outubro de 2026). Confirme antes de ir.
- Parte dos preços tem de 1 a 3 anos; conte com 10–20% a mais.
- A maioria das casas da Liberdade fecha por volta das 22h. Chegue até as 20h.
